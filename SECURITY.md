# Security and release verification

Do not disable Chrome, SmartScreen, or antivirus protection to obtain this program. If a security product reports a malware detection, keep the exact product name, detection name, file name, SHA-256, and date, then report it through the project's issue tracker without uploading private audio projects or configuration files.

Release assets are checked with the published SHA-256 list. A matching checksum confirms that the download matches the published artifact; it does not prove that a file is safe.

This project does not collect credentials, send audio, modify REAPER projects, or change audio routing. It creates or removes only its own current-user startup shortcut when the user chooses that setting.
