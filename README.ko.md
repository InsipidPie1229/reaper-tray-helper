# REAPER Tray Helper

REAPER Tray Helper는 별도로 설치된 REAPER를 시작하고, 창을 시스템 트레이에 숨기며, 원하는 트랙에 전역 음소거 단축키를 지정하는 Windows용 비공식 도우미입니다.

Cockos 또는 REAPER와 제휴·승인·지원 관계가 아닙니다. REAPER 본체, REAPER 라이선스, 플러그인, 오디오 설정 및 프로젝트 파일은 이 프로그램에 포함되지 않으며, 각 사용자가 별도로 준비해야 합니다.

## 다운로드

GitHub 계정이 없어도 [공개 릴리스 페이지](https://github.com/InsipidPie1229/reaper-tray-helper/releases)에서 받을 수 있습니다. 최신 릴리스의 **Assets**에서 `-Source.zip`이 붙지 않은 사용자용 ZIP을 다운로드하세요. 현재 파일은 공개된 사전 릴리스이며 정식 안정 버전은 아닙니다. ZIP을 먼저 압축 해제한 뒤 EXE를 실행하세요. 영어 안내는 [README.md](README.md)를 참고하세요.

## 지원 환경

- Windows 10/11 x64
- .NET Framework 4.8 또는 호환되는 Windows .NET Framework 4.x 런타임
- 별도로 설치한 REAPER

이 배포본은 코드 서명되지 않았습니다. Discord DM으로 파일을 공유했을 때 경고가 있었지만, 이후 GitHub Release에서 받은 파일은 경고 없이 다운로드됐다는 보고가 있습니다. 다운로드 경로 또는 파일 평판이 영향을 줬을 가능성과 맞지만, 당시 경고 문구와 비교한 파일 해시가 없어 원인을 확정할 수는 없습니다. Chrome은 위험한 파일뿐 아니라 낯설거나 드문 파일도 경고할 수 있고 ([Chrome 도움말](https://support.google.com/chrome/answer/6261569)), Windows SmartScreen도 앱 평판을 확인합니다 ([Microsoft 지원](https://support.microsoft.com/en-us/office/protect-my-pc-from-viruses)). 악성코드 경고를 무시하지 마세요. SHA-256은 파일이 배포본과 같은지 확인할 뿐 안전성을 증명하지 않습니다.

## 설치와 최초 설정

1. Release의 사용자용 ZIP을 삭제하지 않을 폴더에 압축 해제합니다. EXE와 동봉된 `ReaperTrayHelper_ToggleTrackMute.lua`를 같은 폴더에 둡니다.
2. `ReaperTrayHelper.exe`를 처음 실행합니다.
3. 설치된 `reaper.exe`를 선택합니다. 자동으로 열 프로젝트가 있다면 `.rpp`도 선택합니다.
4. Windows 로그인 시 시작하려면 `Windows 로그인 시 REAPER 자동시작`을 체크하고 저장합니다.
5. 설정 오른쪽 위의 `표시 언어`에서 `자동 (Windows)`, `한국어`, `English`를 선택할 수 있습니다. `자동`은 Windows 표시 언어가 한국어이면 한국어, 그 외에는 영어를 사용합니다. 저장하면 트레이 메뉴와 이후 설정 창에도 선택한 언어가 적용됩니다.

## 전역 단축키 처음 설정하기

이 연결은 처음 한 번만 설정하면 됩니다. 설정하는 동안 REAPER와 REAPER Tray Helper를 모두 실행해 두세요. 사용자용 ZIP을 아직 풀지 않았다면 먼저 원하는 폴더에 압축을 풉니다. 그 폴더 안에 `ReaperTrayHelper.exe`, `README.md`, `LICENSE`와 **`ReaperTrayHelper_ToggleTrackMute.lua`**가 있어야 합니다. Lua 파일은 REAPER에서 실행할 작은 연결 스크립트입니다. 파일을 메모장으로 열거나 내용을 복사할 필요는 없습니다.

### 1단계: REAPER에 OSC 컨트롤 서피스 추가

1. REAPER 위쪽 메뉴에서 **Options → Preferences…**를 엽니다. Preferences 창의 왼쪽 목록에서 **Control/OSC/web**을 선택합니다. 한국어 화면에서는 항목 이름이 번역되어 있을 수 있습니다.
2. 오른쪽의 **Add**를 누르고 **OSC (Open Sound Control)**를 선택한 뒤 확인합니다.
3. OSC 설정 창에서 **Mode**를 **Configure device IP+local port**로 선택합니다. 이 모드는 아래 IP와 포트 입력란을 설정할 수 있게 합니다. 맨 위의 **Control surface mode**는 이미 **OSC (Open Sound Control)**로 선택되어 있어야 합니다.
4. 다음 값을 입력합니다.

   | REAPER OSC 항목 | 입력값 |
   | --- | --- |
   | Pattern configuration | `Default.ReaperOSC` |
   | Device IP | `127.0.0.1` |
   | Device port | `9001` |
   | Local listen port | 도우미 설정의 `REAPER OSC 로컬 수신 포트` 값 (처음 설정할 때 기본값 `8000`) |

   `Local listen port`와 도우미의 `REAPER OSC 로컬 수신 포트`는 **같은 숫자**여야 합니다. 다른 OSC 장치가 이미 8000 포트를 사용 중이면 둘 다 사용하지 않는 다른 포트 번호(1024~65535)로 바꾸세요.
5. 확인을 눌러 OSC 설정을 저장하고, Preferences 창에서도 **Apply** 또는 **OK**를 누릅니다. 컨트롤 서피스 목록에 OSC 항목이 남아 있는지 확인합니다.

### 2단계: Lua 스크립트를 REAPER 액션 목록에 등록

1. REAPER의 **Actions → Show action list…**를 누릅니다. 액션 목록은 `?` 키로 열 수도 있습니다.
2. 열린 Action List 창 아래쪽의 **New action…** 버튼을 누릅니다. 메뉴에서 **Load ReaScript…**를 선택합니다. 이 메뉴는 Actions 메뉴가 아니라 Action List 창의 **New action…** 버튼에 있습니다.
3. 파일 선택 창에서 압축을 푼 도우미 폴더를 열고 `ReaperTrayHelper_ToggleTrackMute.lua`를 선택한 뒤 엽니다. 찾기 어렵다면 파일 탐색기에서 ZIP을 푼 폴더를 다시 확인하세요. 이 파일은 EXE와 같은 폴더에 들어 있습니다.
4. 스크립트를 불러오면 Action List에 `ReaperTrayHelper_ToggleTrackMute.lua`라는 이름의 액션이 나타납니다. 검색 칸에 `ToggleTrackMute`를 입력하면 찾기 쉽습니다.
5. 해당 액션 행을 마우스 오른쪽 버튼으로 누르고 **Copy selected action command ID**를 선택합니다. 명령 ID는 보통 `_RS`로 시작합니다. 이 ID가 클립보드에 복사됩니다.

### 3단계: 도우미에서 연결 시험

1. 작업 표시줄 오른쪽 알림 영역의 REAPER Tray Helper 아이콘을 마우스 오른쪽 버튼으로 누르고 **설정**을 엽니다. 아이콘이 안 보이면 작업 표시줄의 `^` 숨겨진 아이콘 버튼을 확인하세요.
2. 설정 화면의 **REAPER OSC 로컬 수신 포트**가 REAPER의 **Local listen port**와 같은지 확인합니다. 기본값은 `8000`입니다.
3. **ReaScript 명령 ID** 칸을 클릭하고 앞에서 복사한 ID를 붙여 넣습니다 (`Ctrl+V`).
4. **OSC 연결 시험**을 누릅니다. “REAPER Lua 스크립트와 연결되었습니다.”라는 메시지가 나오면 연결된 것입니다. 실패하면 아래 문제 해결 항목을 확인하세요.
5. 이제 이 설정 창에서 **추가**를 눌러 트랙별 단축키를 등록할 수 있습니다. 변경을 마치면 **저장**을 누릅니다.

### 4단계: 트랙과 단축키 지정

1. 도우미 설정의 단축키 목록에서 **추가**를 누릅니다.
2. `트랙 이름` 칸에 REAPER 트랙 패널에 표시된 이름을 정확히 입력합니다. 공백과 한글도 이름의 일부입니다. 예를 들어 트랙 이름이 `MIC`이면 `MIC`라고 입력합니다.
3. 단축키 입력 칸을 클릭한 다음, 원하는 조합을 동시에 누릅니다. 예: `Ctrl+Alt+1`. `Ctrl`, `Alt`, `Shift` 중 하나 이상과 일반 키를 조합해야 합니다. `F12` 및 일부 예약 키는 사용할 수 없습니다.
4. 확인한 뒤 목록에 트랙 이름과 단축키가 표시되는지 보고 **저장**을 누릅니다. 다른 트랙도 같은 방법으로 추가할 수 있습니다. 동일한 단축키나 동일한 트랙 이름을 두 번 지정할 수 없습니다.
5. 시험할 때는 해당 트랙 이름이 정확히 한 번만 있는 프로젝트를 REAPER에서 활성화합니다. 설정한 단축키를 누르면 그 트랙 하나만 음소거/해제됩니다. 성공하면 알림 영역에 현재 상태가 표시됩니다.

### 연결이 안 될 때

- **OSC 연결 시험에 응답이 없음:** REAPER가 실행 중인지, OSC 컨트롤 서피스가 목록에 있고 활성화되어 있는지, REAPER의 `Local listen port`와 도우미의 포트가 같은지 확인합니다. 처음 연결할 때는 기본 `8000`을 그대로 사용해 보세요.
- **잘못된 명령 ID:** Action List에서 스크립트 액션을 다시 찾아 우클릭하고 **Copy selected action command ID**를 선택한 뒤, 도우미 칸에 다시 붙여 넣습니다. 이름만 직접 입력하면 안 됩니다.
- **단축키를 저장할 수 없음:** 다른 프로그램이나 Windows가 그 조합을 이미 쓰고 있을 수 있습니다. 다른 조합을 입력하고 다시 저장합니다. 저장이 거부되면 기존에 적용된 단축키는 유지됩니다.
- **트랙이 바뀌지 않거나 오류 알림이 나옴:** 도우미가 실행 중인지, REAPER에서 대상 프로젝트 탭이 활성화되어 있는지, 트랙 이름이 완전히 일치하고 프로젝트 안에 한 번만 있는지 확인합니다.

단축키는 도우미가 실행 중일 때만 작동합니다. REAPER 창이 다른 프로그램 뒤에 있거나 트레이에 숨겨져 있어도 사용할 수 있지만, REAPER가 종료되어 있으면 작동하지 않습니다. 이 기능은 REAPER 프로젝트의 트랙 음소거만 제어하며 REAPER 밖의 마이크 신호 경로는 제어하지 않습니다.

설정은 `%LOCALAPPDATA%\ReaperTrayHelper\settings.xml`에 저장됩니다. 자동시작은 현재 Windows 계정의 시작프로그램 바로가기 `REAPER Tray Helper.lnk`로만 등록됩니다.

## 사용법

- 새로 시작한 REAPER는 주 창이 준비된 뒤 약 2초 후 트레이로 숨겨집니다.
- 트레이 아이콘을 더블 클릭하면 REAPER 창을 열거나 숨깁니다.
- 아이콘을 우클릭하면 열기·숨기기·설정·도우미 종료 메뉴를 사용합니다.
- 도우미를 종료하면 숨긴 REAPER 창을 표시하고, REAPER 자체는 종료하지 않습니다.
- 설정에서 자동시작 체크를 끄고 저장하면 해당 바로가기를 제거합니다.
- 도우미가 실행 중이면 REAPER가 다른 창 뒤에 있거나 트레이에 숨겨져 있어도 전역 단축키가 작동합니다.
- 설정에서 단축키를 추가하고 트랙 이름을 정확히 입력한 다음 단축키 입력 칸에서 원하는 조합을 누릅니다. 예: `Ctrl+Alt+D1` → `MIC`, `Ctrl+Alt+D2` → `MUSIC`.
- 한 단축키는 지정 트랙 하나의 음소거만 토글합니다. 성공하면 트레이 알림에 현재 상태가 표시됩니다.

## 제한 사항

- REAPER가 이미 실행 중이면 프로젝트를 새로 열거나 기존 창을 숨기지 않고 연결만 합니다.
- 설정한 REAPER가 두 개 이상 실행 중이거나, 권한 차이 때문에 경로를 확인할 수 없으면 연결하지 않고 안내합니다.
- 평가판 안내·오류·저장 확인 같은 대화상자는 자동으로 닫거나 숨기지 않습니다.
- 트랙 이름은 활성 프로젝트에서 정확히 일치해야 하며, 같은 이름이 여러 개면 아무 트랙도 바꾸지 않고 오류를 알립니다.
- 단축키는 도우미가 실행 중일 때만 작동합니다. Windows나 다른 앱이 이미 사용 중인 조합은 저장할 수 없습니다.
- 이 프로그램은 REAPER 트랙의 음소거만 제어합니다. REAPER 바깥으로 직접 전달되는 마이크 신호나 오디오 라우팅은 제어하지 않습니다.
- 창을 숨겨도 REAPER 오디오 처리는 계속될 수 있습니다.

## 제거

도우미 설정에서 전역 단축키를 삭제하고 자동시작 체크를 끈 뒤 저장합니다. REAPER Preferences에서 도우미 OSC 컨트롤 서피스를 제거하고 Actions 목록에서 도우미 ReaScript를 지웁니다. 트레이 메뉴에서 도우미를 종료한 다음 압축 해제 폴더와 `%LOCALAPPDATA%\ReaperTrayHelper` 폴더를 삭제하면 됩니다.

## 소스 빌드와 검증

Windows에서 `build.cmd`를 실행하면 `artifacts` 폴더에 실행 파일, Lua 스크립트가 포함된 사용자용 ZIP, 소스 ZIP, SHA-256 목록이 생성됩니다. 빌드 과정은 설정 파일·전역 단축키 검증·OSC 메시지 형식·자동시작 바로가기 처리·REAPER 프로세스 선택을 자동 검사합니다.

현재 릴리스 후보의 자동 검사 근거와 외부 Windows PC 검증 상태는 [TESTING.md](TESTING.md)를 참고하세요. 다른 Windows PC에서 안정적으로 사용했고 이전 Chrome 경고가 더 이상 나타나지 않았다는 사용자 보고를 반영했습니다. 다만 경고의 당시 문구와 다운로드한 파일 해시는 기록되지 않아, 현재 릴리스는 사전 릴리스로 표시합니다.
